# Stack 0.1.3 benchmark fixtures

These examples and six E2E scenarios come from release commit
`a1358335984610926384c58d9a83bd383301d647`. The MCP scenario includes the
evaluation's correction to assert the exact nine tool names instead of seven.

The release benchmark runners use this directory so later product changes do
not change the meaning of a 0.1.3 rerun. Results remain in `eval/results/`.
The original run's script hashes are preserved with those results; they describe
that run, before the runners were changed to select these frozen fixtures.
